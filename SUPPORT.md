# Getting help

mimikr has no release yet.
You run it from the source, as the [README](README.md) says.

## Understand the project

- [README.md](README.md) says what the project is and how to start it.
- [docs/roadmap.md](docs/roadmap.md) holds the order that the work happens
  in, and the test that ends each phase.
- [docs/milestones.md](docs/milestones.md) holds each decision and the reason
  for it.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository, human or agent.
- [TERMS.md](TERMS.md) says what you agree to when you make an identity of a
  real person.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/mimikr/issues) first, in case
  somebody has already asked.
- If you found a bug, open a bug report.
- If you want a feature, open a feature request.

When you report a problem, name the model server, the model, and your
operating system.
Run `uv run mimikr check` and put its output in the report.

**Do not attach a real transcript or a real personality file.**
Make a short example that shows the problem, with invented names.

Do not use the issue tracker for security problems.
See [SECURITY.md](SECURITY.md) for how to report those privately.
